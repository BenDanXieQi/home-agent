# Agent 评估

backend → Agent → 模型调用通过共享 OpenTelemetry 基建追踪，可选导出到 LangSmith；配置与范围见 [追踪接入](../docs/observability.md)。目前尚无 eval runner 或远程数据集，tracing 不代表评估已完成。

当前可规划的场景：

| 场景               | 预期                                   |
| ------------------ | -------------------------------------- |
| 缺少模型配置       | API 返回 503                           |
| 请求查询或控制设备 | 明确说明尚未接入设备，不伪造状态或动作 |
| 单次对话           | SSE 返回内容及明确的结束事件           |
| 取消与超时         | 取消模型执行，不留下后台任务           |

未来接入原生 JS 设备能力后，再加入工具选择、真实设备 ID、业务错误和动作确认场景。持久会话与自动化任务实现后再定义幂等与恢复评估。新增测试需事先取得用户明确许可。
