## 非人声候选与有限观察

当前纯音频候选支持非空转写及可选本地猫狗声音分类，配置与未覆盖限制见[猫狗声音识别与捕获](../perception.md#猫狗声音识别与捕获)。其他未分类环境声音仍可能被筛除；Silero VAD 只检测人声，不能承担环境声音分类。

- 其他非人声入口复用已有 PCM、能量观测和窗口，按授权音轨、声音活动、持续时间及最低间隔筛出有界片段；未分类时只表示声音活动，不命名猫叫或需求。
- 扩展声音类别时保留分数、版本和未知结果；也可按授权与预算把原始音频交给已验证支持音频的模型。非人声不经 ASR 臆造文字，不默认同时分类、转写和调用大模型。
- 有限周期观察及调查补查限定来源、区间、模态、最大帧数／音频时长、截止和预算。明确启用的职责可以查看静止画面，不要求先有设备自动化规则；未通过筛选的全部窗口不能换名补发。
- 音频触发后的视觉补证另行申请，返回实际取得材料及缺口；纯音频候选不保证已有可读视频，也不能确认哪个成员或宠物发声。

候选身份包含音轨、运行、实际区间和分析版本。重叠候选只按有界时间策略合并，不证明属于同一只宠物或同一次现实活动。断流不等于安静或问题解决；前后片段、遮挡和同步精度未知均进入覆盖限制。持续责任、等待和通知频率由 Agent 工作拥有。

## Agent 媒体输入与恢复

即时窗口文字／事实查询属于协作设计 A，不等于媒体理解。可恢复媒体调查属于 D：依赖 B 的家庭与工作基础、C/D 共用运行与调用存储，以及材料保留，不依赖 C 的变更消费先交付。模型适配与真实模态验证可提前独立开展。

backend 拥有来源资格、证据和媒体，Agent 拥有模型适配、任务解释及执行。工具返回 URL 不等于模型收到字节。模型与端点分别验证无音轨视频、纯音频、带音轨视频；支持其中一项不能推定其他项。转写可以作为有来源的文字输入，不能据此声称模型听过声音。不支持声音的端点明确返回能力限制，独立音频调用须显式启用并计入预算。

材料请求明确所需表示、实际区间与最晚使用时间，backend 返回准备中、就绪或缺失。触发前材料须实际存在，触发后等待有截止；跨窗口补证返回覆盖、时间质量和缺口，不拼成未经证明的连续活动。冻结来源、原时间、原帧与坐标、处理版本及内容标识；补查新增输入快照，不覆盖前次输入或用新画面替换失效材料。

短期媒体沿用[当前期限](../perception.md#容量停止与访问期限)。承诺排队或跨重启读取前，必须取得必要字节的持久保留回执；文字、媒体读取与结果提交期限分别管理。文件与数据库分别恢复，缺失字节明确返回缺失。每次读取、外发和提交重新核验资格；已交给外部模型的字节不能声称已收回。具体容量、落盘及调用恢复统一引用[材料与执行输入](household-storage.md#材料与执行输入)。

结果区分本窗可见内容与跨来源推断并引用依据，默认属于任务解释。稀疏帧、静止、未检出或证据到期不证明连续无人、睡眠或完整活动；共享判断须有实际消费者及单独接纳规则。Agent 停止不影响本地采集，未接纳媒体仍按原限额过期。

## 身份生产者扩展

当前本地人物和猫狗参考、匹配、成员关联及活动纠正见[持续成员身份分析](../perception.md#持续成员身份分析)。沿用 backend 身份领域，不重建本地识别链路；Agent 最近出现查询属于协作设计 A，按当前归因和最后观察查询，摄像头安装房间不能冒充成员位置。

如接入 LLM 身份核验，使用 Agent 媒体执行路径，提交带参考版本及实际视觉证据的候选，由家庭身份领域核对、接纳与纠正。身份选帧不依赖窗口关闭或场景变化，屏蔽目标此前的身份猜测与习惯先验；参考过期本身不触发无条件模型调用。本地与 LLM 路径独立启用，不默认双重调用；纯音频不产生视觉身份确认。

联合核验按明确问题选择有限多源画面，保留各路时间和同步限制，不把最新帧伪装为同时拍摄。自动参考样本积累、跨来源等待或新增模型另定资格、纠错与资源预算，未选定消费者前不创建在线模块。

## 扩展完成条件

- 非人声入口分别核对猫叫、犬吠、电视人声及背景噪声的漏接与误触发；声音活动与声音类别独立验收。
- 有限观察核对职责、授权、来源、预算、停止条件和取消，不以现有变化筛选代替新增入口。
- 媒体补证核对触发前不足、触发后断流、覆盖、容量与取消；排队过期、重启及撤权按实际保留承诺验收。
- 模型实际取得并理解所需模态，解析失败、输入缺失及端点限制可见，不以 HTTP 成功代替效果。
- 新身份生产者核对参考、版本、质量、迟到结果与纠正；效果和联合资源按实际启用能力测量，不扩大已有本地验证范围。

交付后把用法和未覆盖限制归入当前功能文档，移除对应计划事项。
