# 设备状态、历史与家庭情景页面

**状态：房间事实、一次性读取和 AI 观测描述已接入；历史、活动、画像与动作条件展示待实施。** 当前行为见[设备事实](../contracts/device-facts.md)、[房间 AI 上下文](../contracts/room-analysis.md)、[家庭运行时](../household-runtime.md)和 [Web README](../../apps/web/README.md)。本文只定义剩余页面增量。

[实施入口](README.md)

## 数据边界

复用现有共享 schema、状态 SSE、版本检查与批次应用。页面消费后台已提交状态，命令响应不直接覆盖事实，不建立第二份当前值缓存。事实仍来自家庭运行时，判断、画像、活动和动作条件来自各自领域所有者；不能从自然语言总结反推出结构化状态。

设备原始值、AI 推断、用户明确要求、建议动作、请求发出、设备响应和效果核对分别展示。未知不显示成无人、关闭或零；判断显示证据、冲突、时间和有效性。用户提问返回答案与证据，后台分析须在房间或活动入口显示接纳结果或明确失败，不能只保存到 Agent 运行检查点。

## 历史查询

按[设备历史](device-history.md)接入有界分页，缓存键包含绑定身份、能力、时间和过滤条件。取消传到请求，关闭周期、聚焦和重连自动刷新；不在浏览器下载解析全量记录。

原始观测、来源质量、实际保留范围、裁减及缺口可见，不插值暗示完整连续状态。历史响应不覆盖当前值，浏览器未同步与设备离线分别显示。历史写入健康通过后台提交的状态显示，详细缺口按需查询，不要求先打开查询才能看到保存故障。

## 家庭情景与操作

随[协作计划](household-automation.md)逐项接入：

| 视图       | 待展示内容                                           |
| ---------- | ---------------------------------------------------- |
| 当前判断   | 人物／宠物的位置、活动、证据、冲突和失效状态         |
| 动作条件   | 具体动作的允许、禁止或未知，适用范围、原因与结束条件 |
| 活动记录   | 近期经过、上一次已确认活动、修正与必要证据           |
| 家庭档案   | 确认身份、设备关联、明确偏好；推测习惯单独标注       |
| 分析与执行 | 触发原因、接纳或拒绝原因、动作建议与实际执行结果     |

先提供必要的身份确认、偏好修改、活动纠正和规则启用信息，不以完整规则或户型编辑器为前置条件。修改由后台校验并重新评估受影响判断。

设置页已有的家庭切换确认与失败处理继续沿用；新增档案、历史、活动和任务数据须同步纳入清理提示及后台清理，不跨家庭复用。

## 同步与验收

传输、慢连接、重连及访问限制沿用现有接口；新能力交付时才接入对应字段和查询，不预先注册空接口。状态重连补当前快照，不承诺补发全部历史活动。

- 异步响应核对家庭、房间／实体及适用版本，切换对象或离开页面后不写错视图。
- 局部失败不清空其他有效事实；心跳和重新获取快照不能让旧证据变新。
- 历史查询与保存失败不影响当前事实，多页面不增加云端读取或周期轮询。
- 过期判断不能继续显示为有效；控制建议与执行结果区分，实际动作按具体场景验收。
- “上一次”活动与偏好有来源及不足说明；缺失记录不被解释为从未发生。
