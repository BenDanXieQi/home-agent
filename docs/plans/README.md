计划只维护尚未交付的能力及其验收要求。当前用法、配置和验证限制见[文档导航](../README.md)、[设备事实](../contracts/device-facts.md)和[本地感知](../perception.md)。

| [媒体能力扩展](media-perception.md) | 非人声候选、有限观察、Agent 媒体输入及身份生产者扩展 |

本地感知可独立交付。已有家庭数据通路的用法与验证限制统一见[当前数据与材料历史](../household-runtime.md#agent-当前数据与材料历史)，设备历史部署限制见[设备状态历史](../household-runtime.md#设备状态历史)；本文不另维护路线或存储设计。

## 每项交付的检查

- 明确实际来源、消费者、输出用途及不确定性；未实现能力不写成当前功能。
- 校验访问范围、迟到输入、取消、容量与故障隔离，按具体能力核对恢复承诺。
- 复用原生能力和成熟库，不提前安装无消费者依赖或创建空模块；持久唤醒、事务和媒体分别引用所属计划。
- 真实设备、源码审查与模拟输入的证据分开；纯文档只检查文档，未经用户明确许可不新增测试或故障注入脚本。
- 交付后把用法和验证限制更新到所属功能文档，从计划移除完成事项，不保留一次性进度日志。

原始验证材料保留在 Git 忽略的 `data/verification/` 或 `data/perception/`，共享文档不保存账号、凭据和一次性运行报告。
