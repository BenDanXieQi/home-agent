## 页面交付

工作页面随协作设计各批次接入，不预建空接口：观察记录显示当前归因、来源、观察时间、修订与材料可读性；职责显示确认时间、时区、通知目标、期限及停止条件；调查显示实际输入、补查、等待与缺口；动作显示授权、接纳或阻止原因、渠道回执与未知结果。改期、取消和恢复取得后端交接确认后才显示生效，设置中或结果未知须明确展示，不因重复点击创建新效果身份。

稳定本地家庭交付时同步调整 Web 门禁与清理提示，区分来源解绑和明确家庭重置，具体行为以[家庭生命周期](household-automation.md#家庭生命周期)为准。设备历史页面要求见[历史页面](device-history.md#历史页面)。当前页面行为继续由 [Web README](../../apps/web/README.md)维护。

## 按需采集诊断

现有[限时上报日志](../household-runtime.md#设备上报日志)继续独立使用。仅在真实来源验证需要时扩展规范化统计与录制：收到、变化、同值、无效及可确认重复分别计数，身份不可验证时重复率保持未知；录制默认关闭，仅保存校验观测，不含凭据。初始上限为 24 小时、100,000 条或 128 MiB，任一达到停止；本机文件总量有界，写入失败不阻塞采集。该能力尚未实现，不是历史保存的前提。

## 每项交付的检查

- 明确实际来源、消费者、输出用途及不确定性；未实现能力不写成当前功能。
- 校验访问范围、迟到输入、取消、容量与故障隔离，按具体能力核对恢复承诺。
- 复用原生能力和成熟库，不提前安装无消费者依赖或创建空模块；持久唤醒、事务和媒体分别引用所属计划。
- 真实设备、源码审查与模拟输入的证据分开；纯文档只检查文档，未经用户明确许可不新增测试或故障注入脚本。
- 交付后把用法和验证限制更新到所属功能文档，从计划移除完成事项，不保留一次性进度日志。

原始验证材料保留在 Git 忽略的 `data/verification/` 或 `data/perception/`，共享文档不保存账号、凭据和一次性运行报告。
