## 范围与实现

复用唯一账号所有者和当前选定家庭的设备目录。扫码后由后端完成 OAuth 授权，MiCloud 与 OAuth 凭据统一保存、恢复、续期及清除，不新增独立登录入口、账号映射或凭据仓库。

- [x] `service.ts` 提供 `observeDevices(deviceIds, onObservation, signal)`：账号与目录校验、共享连接、取消和生命周期失效处理。
- [x] `protocols/miot/mqtt.ts` 使用锁定的 MQTT.js 5.16.0，MQTT 5/TLS、60 秒心跳、15 秒连接期限、clean start。实例 UUID 与账号 OAuth 绑定，使用 32 位无连字符十六进制格式。
- [x] 每设备建立属性和在线 topic，多个观察者共享订阅；16 个在途名额、10 秒确认期限，逐 topic 区分期望、在途、确认及失败，仅 SUBACK QoS 0/1/2 算成功。
- [x] 消息回调先于订阅注册；当前实例内仍被观察的合法早到消息可交付，收到消息不代替 SUBACK。
- [x] `protocols/miot/messages.ts` 校验属性 method、did、siid/piid 与显式存在的标量 value，支持 params 对象和数组，不按 notify 白名单过滤。在线叶子仅接受 online/offline；带 `/` 或通配符的 did 报告限制。
- [x] 输出稳定来源、采集实例、真实接收时间及 live/baseline；缺失设备时间、业务事件 ID 和序号均为 null，同值上报保留。
- [x] 取消移除回调、退订无消费者 topic；退出、范围变更和凭据替换关闭旧实例，迟到消息和确认不能复活它。MQTT 局部失败不直接关闭媒体。
- [x] 来源契约、`properties/source-profiles.ts`、调用方式与本机报告同步更新。
