# 家庭自动化规则

自动化规则由 Backend 管理和执行，Agent 只负责根据自然语言生成可审阅草稿。当前支持设备属性条件、时间窗口和固定动作；AI 判断条件与 AI 动作选择尚未启用。相关契约与表结构不表示这些模型执行能力已经可用。

## 使用与配置

配置数据库并执行仓库根目录的 `bun run db:migrate`，迁移链中的 `0016_automations.sql` 创建自动化表。规则页面位于 `/automations`，可手动编辑、生成草稿、保存、启停和查看执行记录。生成需要独立 Agent 进程及模型配置，固定规则求值与设备执行不依赖 Agent 在线。

新草稿默认停用，用户核对条件、动作及生成说明后再启用。数据库不可用时不能管理或执行规则。规则数量上限为每家庭 100 条；生成不保存、不启用、不执行设备操作。当前没有聊天工具用于保存、删除或执行规则。

## 条件与触发

规则使用 AND、OR、NOT 条件树，NOT 只能有一个子节点。每个条件标注“触发”或“状态”：触发节点同时参与判断，并声明开始满足、退出满足、持续满足或独立事件发生；状态节点只检查当前条件，自身变化不会执行动作，也不补发先前被阻止的触发。

例如“有人且光线暗就开灯”可把两者均标为触发，任一条件最后成立都能发起执行；“有人进入时，如果光线暗就开灯”则把有人条件的进入标为触发，把光线暗标为状态。设备值只能表达其来源声明的含义，灯关闭不能证明有人睡觉。

求值保留真、假、未知。缺值、离线、过期和无效值保持未知，NOT 不把未知变成真。缓存值可以建立当前条件状态，但属性进入、退出和持续计时的启动需要普通实时报告。首次值、恢复基线和同值报告不会制造新的进入或退出触发；持续条件遇假或未知清除计时，后续由新报告重新开始。冷却到期本身不产生触发。

AND 不要求多个触发同时出现；OR 的触发必须来自证明本次结果成立的分支。退出方式在条件离开原满足状态时生效。时间窗口保存 IANA 时区及 ISO 星期，结束时刻不包含，跨午夜窗口归开始日。手动新建窗口采用浏览器本地时区，编辑时保留已保存时区；边界由 `cron-parser` 计算，原生定时器负责唤醒。

属性类型从设备规格派生，Web、Agent 和 Backend 共用约束：

| 类型 | 运算符与输入                             |
| ---- | ---------------------------------------- |
| 布尔 | 等于、不等于；开／关选择                 |
| 枚举 | 等于、不等于、属于、不属于；规格选项     |
| 数值 | 等于、不等于、大小比较、区间；数字及单位 |
| 文本 | 等于、不等于、包含、不包含；文本输入     |

`value_list` 优先作为枚举，即使底层编码为整数也不提供大小比较。写入属性和动作参数校验格式、整数范围、枚举、范围、步长及参数顺序。未知格式不推测为可用能力。每棵树最多 128 个节点、12 层，每组最多 32 个子节点，每条规则最多 16 项动作。

Backend 按属性、设备维护规则索引，状态变化更新相关条件，时间边界和持续期限由每条规则的最近一个内存定时器唤醒。每次求值同步更新内存状态，不等待数据库、设备或模型。规则状态、持续计时和冷却不跨进程或家庭运行期恢复。

## 自然语言生成

页面调用 Backend 公共 `POST /api/workflows`，指定 `workflow="automation-generation"`。Backend 从当前家庭的已加载规格准备设备能力，经 Agent 公共 workflow 入口执行一次结构化模型调用，返回前重新检查家庭资格和当前设备能力。家庭切换、取消或关闭使在途请求失效。

模型上下文按设备分组，保留属性和动作参数约束。缺少阈值、设备或动作时机存在歧义时返回澄清问题，不擅自补成可执行规则。请求超过上限时拒绝，不截断能力。页面展示草稿说明、待确认问题及补充输入；生成后的草稿仍需人工审阅。

AI 判断条件和动作选择尚未启用：生成器遇到这些要求会说明限制，规则编辑器不提供新增入口，Backend 拒绝启用含这些配置的规则。即使存在这样的停用定义，也不能通过调用接口或重新加载取得执行资格。

模型调用期限、容量与可观测性配置见 [Agent README](../apps/agent/README.md#接口)。当前生成不调用家庭材料或历史工具，不提供持续调查、主动问询或跨来源情景判断。

## 固定动作与执行记录

动作支持写入米家属性、调用设备动作和网页通知。网页通知的成功表示内容保存在自动化执行记录中，没有系统推送、音箱播放或已读保证。设备控制的 `accepted` 只表示供应商接纳，不证明设备已达到目标状态；拒绝、未知、取消与成功分别展示，控制返回不直接改写设备事实。

动作领取及实际发送前检查家庭、规则版本、启停、当前条件、触发连续性、动作期限和设备资格。条件中途转为假或未知再恢复，不继承旧触发资格。修改、停用、删除和家庭切换撤销旧资格；已经发出的请求无法撤回，也不会自动重发。控制发送后超时或进程中断不能证明设备未执行，来源协议边界见[设备控制契约](contracts/mijia.md#设备控制入口)。

内存动作执行器并发上限为四，包括通知；逐设备顺序由米家控制模块负责。同一规则发往不同设备的动作可并行，列表不表达跨设备先后依赖。最多接纳 256 项尚未完成整次执行的动作，容量不足时取消整次动作，不只发送其中一部分。固定动作不等待数据库登记或任务领取。

全部动作完成后汇总结果，由独立串行队列尽力保存触发证据和动作记录。日志队列最多接纳 256 次记录，容量不足或写入失败只丢记录，不重发设备动作。规则修改使用独立串行写入队列，最多接纳 256 项等待与在途操作。冷却从本次命中开始计算，发送或保存失败不重新触发。

后续同属性、同值的普通实时报告可与发送时间关联，记录观测身份和时间；这种关联不是因果证明。页面显示最近 50 次进入执行流程的触发，包含失败和取消；同值报告、基线更新和未满足条件不另写运行日志。

## 保存、恢复与接口

保存使用稳定 ID 和预期版本，相同保存重试返回已有结果，版本冲突要求刷新。保存或删除先撤销内存执行资格，写入失败或提交结果不明时保持暂停；刷新页面核对后再次明确保存才恢复资格。设备能力消失时可保留停用定义，启用时重新校验。

家庭数据使用统一清理登记，切换家庭清理自动化定义、运行、动作、模型相关表及事件表。数据库迁移沿用主干 `0000～0015` 并由 `0016` 创建最终自动化结构；没有旧迁移编号碰撞或历史数据搬迁步骤。

启动、家庭恢复或规则重新启用时重建当前基线，不补跑旧动作。配置读取失败时保持暂停，每分钟重试读取，成功后建立新基线，故障期间输入不重放。触发、队列接纳、设备调用或日志保存失败可能丢失本次工作，不保证零漏报、完整日志或恰好执行一次。

HTTP 均为本机 JSON POST，携带当前 `scope_epoch`：

| 路径                                                         | 用途                   |
| ------------------------------------------------------------ | ---------------------- |
| `/api/household/automations/{list,capabilities,save,delete}` | 规则定义与当前能力     |
| `/api/household/automations/{query,read,capabilities/query}` | 分页查询和单条完整定义 |
| `/api/household/automations/{evaluate,runs}`                 | 节点求值和执行记录     |
| `/api/workflows`                                             | 自然语言规则草稿生成   |

当前没有家庭事件生产者接入，事件能力列表为空；米家独立设备事件 `siid/eiid` 尚未作为自动化触发来源。`household/events/` 提供内部事件身份与接纳，没有任意 HTTP 写入入口，规格中的事件声明不代表已经交付事件触发。

规则契约及纯求值语义由根目录 `packages/api` 提供；Backend 的 `household/automations/` 拥有定义、内存求值、动作调度和记录，`mijia/control/` 负责设备控制适配，Agent 的 `workflows/automation-generation/` 只负责草稿生成。规则条件状态只在内存保存，执行证据保存在 `automation_runs`，没有输入队列或规则状态表。AI 相关表和契约保留，但当前没有复核、动作选择或模型后台任务调度入口。

执行历史每分钟清理，启动期限已过的记录按每条规则最近 1,000 条且不超过七天的限制保留，仍在启动期限内的记录暂留。日志失败不补写、不重试、不补造结果。内部事件保存上限为每家庭 50,000 条，满后拒绝新事件。执行页面不作为永久审计或完整设备历史。

## 验证边界

类型、构建和现有测试不能代替真实设备或模型验收。真实模型生成效果、设备写入与动作调用、供应商结果确认，以及自动化触发到设备反馈的完整链路仍需场景验收。AI 条件、动作选择、音箱输出、独立设备事件、语义事件纠正与撤回、跨来源情景生命周期和 Agent 持续调查均不属于当前启用能力。
