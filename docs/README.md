已完成的实施步骤从计划移除，必要的用法、约束和验证限制归入所属当前文档，不保留整份施工清单或增加归档副本。修改领域语义时同步受影响的实施契约；修改实际行为时更新所属功能说明；新增能力交付后更新其计划状态及使用限制。HTTP、共享 schema、数据库与调用方的变化按真实依赖核对，不复制多份字段定义。验证入口见各应用 README、[后端测试说明](../apps/backend/tests/README.md)、[Web 测试说明](../apps/web/tests/README.md)和[共享契约说明](../packages/api/README.md#测试)；仅运行直接相关的最小范围，新增测试须先取得用户明确许可。

| 文档                                                 | 保留理由与边界                                                                       |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------ |
