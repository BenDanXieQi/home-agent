Harness
pi-durable 的运行器实例，组织会话、模型调用和工具任务。
root
这个 Harness 的主会话句柄。每条聊天消息提交到同一个 root。
Submission
一次已接纳输入的记录与操作句柄，可以等待结果或撤回尚在队列中的输入。

框架保存待处理输入的队列；follow-up 表示当前工作回答后再接着处理。

Chord 的调用上下文，携带取消信号。它不是家庭资料快照，也不是模型消息列表。
scope
当前账号、家庭及运行标识，用来检查资料是否仍属于本次允许读取的范围。
schema
